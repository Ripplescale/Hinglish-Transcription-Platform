# oats 0.7.3

Prepared 7 October 2026 as a local Windows x64 update and a source review.

The application is now **oats**, with the selected Peach Buddy mascot, matching
Windows icons, warm peach colours, and updated notes, settings, onboarding and
meeting prompts. The existing executable, installation identity and `STTApp`
data directory are retained to preserve upgrade compatibility.

Trelis offers **5, 10 or 20 second** windows. New settings default to 10 seconds;
existing saved choices are retained. A conservative Silero speech gate checks
each complete window before recognition. It skips a window only when both the
original signal and an analysis-only amplified copy are confidently below the
speech threshold. A window with brief speech is retained in full. Missing or
failing speech detection keeps the audio and records a diagnostic flag.

Long repeated phrases in a window longer than 5 seconds trigger one retry in
disjoint pieces of at most 5 seconds. The retry replaces the displayed result
only when every piece succeeds, contains text and avoids another long loop.
The original recognition and retry provenance remain available for review.
Failed retries retain the original; 5 second primary windows do not retry
recursively. These safeguards do not guarantee accuracy or completeness.

Soft repetition penalties were tested separately and are **not enabled** in
this release. No hard three-repetition rule or denoising filter is enabled.

## Deployment

The desktop app and updated local worker must be deployed together. Older
workers do not support the new 5 and 10 second Trelis profiles; the app reports
this explicitly. See [worker staging and activation](../SETUP.md#configure-and-install-the-asr-worker).
Worker candidates can be prepared without activating them. Save notes and
close the app normally before installing and activating the paired update.

The unsigned installer is local to the already configured development laptop.
It bundles the desktop app and supporting DLLs, and reuses separately prepared
models and Python environments. Its machine-specific runtime pointer, models,
private recordings and benchmark outputs are excluded from this repository.
This is not a qualified clean-machine or general hardware release.

## Validation

Targeted worker, speech-gate, runtime-history, chunk-selection and native
workflow checks passed during implementation. A bounded replay reproduced and
recovered one repetitive development example; it does not establish general
transcription accuracy or prove that 10 seconds is optimal.

The exported interface passed notes, saved-transcript and meeting-prompt
checks, including compact layouts, autosave, playback, corrections and export.
The [design review](../../design-qa.md) uses fictional demonstration data.
Windows compile checks, branding checks and installer syntax checks passed.
An actual installed upgrade and a physical call remain separate deployment
validation steps.
